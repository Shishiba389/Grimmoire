GRIMOIRE SOP
============

Muc dich
--------
SOP nay dung cho nguoi van hanh/support GRIMOIRE khi chuan bi ban build, gui cho
user test, xu ly loi, va kiem tra tinh on dinh cua he thong.


1. Vai tro
----------
Owner/Builder:
- Cap nhat code.
- Build frontend/desktop.
- Kiem tra health va naming logic.
- Dong goi folder GRIMOIRE.

Tester/User:
- Chay setup.
- Test workflow.
- Gui diagnose report khi co loi.

Support:
- Doc diagnose report.
- Huong dan repair/setup.
- Xac nhan bug va tao task fix.


2. Chuan bi ban gui user
------------------------
Truoc khi zip folder GRIMOIRE:

1. Chay:
   REPAIR_GRIMOIRE.bat

2. Chay:
   DIAGNOSE_GRIMOIRE.bat

3. Kiem tra report:
   diagnostics\grimoire-diagnose-*.txt

4. Kiem tra file desktop ton tai:
   desktop\bin\Release\net10.0-windows\Grimoire.exe

5. Kiem tra frontend asset release:
   desktop\bin\Release\net10.0-windows\wwwroot\index.html

6. Kiem tra khong con hardcode duong dan may goc trong source/script:
   Tim cac chuoi:
   - D:\GRIMOIRE
   - C:\Users


3. Dong goi
-----------
Nen xoa cac thu muc runtime/dependency truoc khi zip neu muon package gon:

- backend\.venv
- backend\node_modules
- frontend\node_modules
- diagnostics
- backend\storage\uploads
- backend\storage\outputs

Khong xoa:
- backend\requirements.txt
- backend\package.json
- backend\package-lock.json
- frontend\package.json
- frontend\package-lock.json
- desktop\bin\Release\net10.0-windows neu muon gui san exe
- SETUP_GRIMOIRE.bat
- REPAIR_GRIMOIRE.bat
- DIAGNOSE_GRIMOIRE.bat


4. Cai dat tren may user
------------------------
Quy trinh user/tester:

1. Giai nen folder GRIMOIRE.
2. Chay SETUP_GRIMOIRE.bat.
3. Chay START_DESKTOP.bat.
4. Test cac workflow chinh.
5. Neu loi, chay DIAGNOSE_GRIMOIRE.bat va gui report.


5. Checklist verify sau moi thay doi
------------------------------------
Backend:
- Python source compile OK.
- import main OK.
- /health OK.
- /api/ean-renamer/health OK.
- /api/ean-sorter/health OK.
- /api/packshot-browser/health OK.

Frontend:
- npm build OK.
- Asset moi duoc tao trong frontend\dist.
- desktop wwwroot duoc cap nhat sau build desktop.

Desktop:
- dotnet build Release OK.
- Grimoire.exe ton tai.
- Grimoire.dll timestamp moi.
- wwwroot\index.html tro dung asset moi.

EAN Renamer:
- Preview dung output path.
- Prefixed duplicate 1st dung chung number cho file khac extension.
- Product Name khong override Prefix neu checkbox EAN_ProductName khong tick.
- Product Name continuous chay dung khi checkbox EAN_ProductName duoc tick.

Packshot Browser:
- Scan folder anh OK.
- Thumbnail/meta endpoint OK voi it nhat 1 anh.
- Copy selected tao file output va packshot_browser_report.csv.
- Cloud-only file duoc thu Windows cached thumbnail bang /shell-thumb, sau do SharePoint online thumbnail bang /online-thumb neu co token.
- /thumb va /file voi cloud-only phai bi chan; chi Copy selected moi doc file va trigger OneDrive download.


6. Lenh verify khuyen nghi
--------------------------
Chay Python compile:

backend\.venv\Scripts\python.exe -m py_compile backend\main.py

Build frontend:

cd frontend
npm.cmd run build

Build desktop:

dotnet build desktop\Grimoire.Desktop.csproj -c Release -t:Rebuild

Health check:

powershell -NoProfile -ExecutionPolicy Bypass -Command "Invoke-RestMethod http://127.0.0.1:7788/health"
powershell -NoProfile -ExecutionPolicy Bypass -Command "Invoke-RestMethod http://127.0.0.1:7788/api/ean-renamer/health"
powershell -NoProfile -ExecutionPolicy Bypass -Command "Invoke-RestMethod http://127.0.0.1:7788/api/ean-sorter/health"
powershell -NoProfile -ExecutionPolicy Bypass -Command "Invoke-RestMethod http://127.0.0.1:7788/api/packshot-browser/health"


7. SOP xu ly loi user
---------------------
Buoc 1: Hoi user dang dung workflow nao:
- Data QC
- Image Edit
- Images Check
- Packshot Browser
- EAN Sorter
- EAN Renamer
- Desktop launch/setup

Buoc 2: Yeu cau user chay:
DIAGNOSE_GRIMOIRE.bat

Buoc 3: Doc report:
- Python co tren PATH khong.
- Node/npm co tren PATH khong.
- backend\.venv co ton tai khong.
- backend/frontend node_modules co ton tai khong.
- Desktop exe va wwwroot co ton tai khong.
- Backend import/build co OK khong.
- Port 7788/5173 co bi chiem khong.

Buoc 4: Neu dependency loi:
- Huong dan user chay REPAIR_GRIMOIRE.bat.

Buoc 5: Neu van loi:
- Yeu cau user gui report moi.
- Yeu cau screenshot loi.
- Yeu cau sample input neu loi lien quan data/image.


8. SOP EAN Renamer
------------------
Quy trinh test chuan:

1. Tao folder source co folder con la EAN.
2. Dat anh .jpg va .png cung noi dung vao folder EAN.
3. Mo EAN Renamer.
4. Pick Folder.
5. Keo anh vao Duplicate > PACK SHOT.
6. Bat 1st o PACK SHOT duplicate box.
7. Chon Naming mode = Prefixed.
8. Bam Preview.

Ket qua mong doi:

Packshot/{EAN}/{EAN}_Pack_shot_1.jpg
Packshot/{EAN}/{EAN}_Pack_shot_1.png

Neu co anh packshot thu hai:

Packshot/{EAN}/{EAN}_Pack_shot_2.jpg

Test Product Name:

Case A:
- Nhap Product Name.
- Khong tick EAN_ProductName.
- Naming mode = Prefixed.

Ket qua mong doi:
{EAN}_Pack_shot_1.jpg

Case B:
- Nhap Product Name.
- Tick EAN_ProductName.

Ket qua mong doi:
{EAN}_{PRODUCT_NAME}_1.jpg


9. Quy tac release
------------------
Chi release khi:

- SETUP_GRIMOIRE.bat chay duoc tren may dev.
- REPAIR_GRIMOIRE.bat chay duoc tren may dev.
- DIAGNOSE_GRIMOIRE.bat tao report duoc.
- Frontend build OK.
- Desktop build OK.
- Health endpoints OK.
- Khong con hardcode path may dev trong source/script.


10. Ghi chu bao mat va data
---------------------------
- Khong gui folder backend\storage\uploads neu co data khach hang.
- Khong gui backend\storage\outputs neu co output that.
- Khong gui diagnostics neu report co username/path may noi bo, tru khi can support.
- Khong dat API key/private token trong source.
