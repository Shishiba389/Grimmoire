GRIMOIRE USER GUIDE
===================

Muc dich
--------
GRIMOIRE la bo cong cu lam viec voi product data va product images, gom cac module:

- Dashboard
- Data QC
- Image Edit
- Images Check
- Packshot Browser
- EAN Sorter
- EAN Renamer
- Settings


Chon nhanh tab theo truong hop
------------------------------
- Can audit master data, missing data, duplicate, rule validation:
  dung Data QC.
- Can resize/crop/canvas/upscale/remove background anh hang loat:
  dung Image Edit.
- Can review folder anh va xoa anh loi/khong can:
  dung Images Check.
- Can tim packshot theo EAN/folder/filename, hover preview va copy anh:
  dung Packshot Browser.
- Can scan barcode/EAN tren anh va sort file vao folder:
  dung EAN Sorter.
- Can copy/rename anh product theo EAN va category:
  dung EAN Renamer.
- Can xem huong dan trong app:
  dung tab Guide.


1. Mo ung dung
--------------
Chay file:
START_DESKTOP.bat

Neu muon chay che do browser/dev:
START_GRIMOIRE.bat


2. Dashboard
------------
Dashboard la man hinh tong quan. Tu day co the mo nhanh cac tool:

- Data Quality Control
- Image Edit
- Images Check
- Packshot Browser
- EAN Sorter
- EAN Renamer


3. Data QC
----------
Muc dich:
- Kiem tra file master data.
- Phat hien loi thieu data, sai format, duplicate, hoac rule validation.
- Tao report de review.

Quy trinh co ban:
1. Mo tab Data QC.
2. Upload/chon file master data.
3. Chay audit.
4. Xem ket qua loi.
5. Export report neu can.

Luu y:
- File input nen la Excel/CSV dung format ma team dang dung.
- Neu report bi loi doc file, kiem tra sheet name/header/format cell.


4. Image Edit
-------------
Muc dich:
- Xu ly anh hang loat.
- Remove background, upscale, canvas edit, export anh.
- Luu custom dimension preset de dung lai lan sau.
- Giu output preview/job gan day de user khong mat ket qua cu khi chay input moi.

Quy trinh co ban:
1. Mo tab Image Edit.
2. Chon/upload anh.
3. Chon Dimension Preset hoac nhap Width/Height rieng.
4. Neu muon dung lai kich thuoc nay, bam Save o Dimension Preset va dat ten preset.
5. Chon workflow can xu ly.
6. Bam Preview (First 1) de xem truoc.
7. Neu dung, bam Start Processing.
8. Xem Outputs o cot phai de chon lai preview/job gan day va download job output.

Luu y:
- Anh lon se ton nhieu RAM va thoi gian xu ly.
- Mot so tinh nang AI can model/dependency day du trong backend.
- Custom preset duoc luu tren may user, lan sau mo app van hien trong dropdown.
- Neu dung output folder local, moi lan chay se tao folder rieng theo timestamp/job id de tranh ghi de output cu.


5. Images Check
---------------
Muc dich:
- Scan folder anh.
- Xem nhanh anh theo folder.
- Mark anh can xoa va xoa sau khi confirm.

Luu y:
- Images Check phu hop de review/clean folder.
- Neu chi muon tim, preview, chon va copy packshot, dung Packshot Browser.


6. Packshot Browser
-------------------
Muc dich:
- Browse folder packshot da sync ve may ma khong can file Excel.
- Search theo EAN, folder, ten file, brand/keyword trong filename.
- Hover vao anh de xem preview lon va thong tin file.
- Chon anh can lay va copy sang output folder.

Quy trinh co ban:
1. Mo tab Packshot Browser.
2. Bam Choose de chon source folder.
3. Bam Scan.
4. Dung sidebar group/folder hoac search de loc anh.
5. Hover vao thumbnail de xem preview va filename chi tiet.
6. Tick anh can copy.
7. Chon output folder.
8. Bam Copy selected.

Output:
- Anh duoc copy sang output folder.
- App tao packshot_browser_report.csv trong output folder.

OneDrive:
- Folder OneDrive da sync co the scan duoc.
- File cloud-only se hien trang thai Cloud.
- App uu tien dung Windows cached thumbnail cho file Cloud, giong thumbnail trong File Explorer.
- Neu Windows chua co cached thumbnail, app thu SharePoint online thumbnail neu da co token dang nhap.
- Neu ca Windows cache va SharePoint thumbnail deu khong co, app hien Cloud placeholder thay vi doc file goc.
- App khong tu tao thumbnail/preview tu file Cloud de tranh OneDrive tu download full file.
- File Cloud chi bi download khi user chon anh do va bam Copy selected.
- Khi Copy selected, OneDrive can internet va OneDrive phai dang chay.


7. EAN Sorter
-------------
Muc dich:
- Scan folder anh.
- Detect barcode/EAN.
- Sort file vao folder theo EAN.

Quy trinh co ban:
1. Mo tab EAN Sorter.
2. Pick folder can scan.
3. Chay scan.
4. Review ket qua EAN/barcode.
5. Ap dung sort/copy tuy theo workflow.

Luu y:
- Neu barcode trung nhau, app co the yeu cau user chon cach xu ly duplicate.
- Anh mo, nho, bi crop barcode co the scan khong chinh xac.


8. EAN Renamer
--------------
Muc dich:
- Doi ten/copy anh product theo EAN va category.
- Ho tro drag-and-drop anh vao cac cot Packshot, Human, Normal Lifestyle, Artwork, Duplicate.


8.1 Chon folder
---------------
1. Mo tab EAN Renamer.
2. Bam Pick Folder.
3. Chon folder source.

App se scan:
- Anh nam truc tiep trong root folder.
- Anh nam trong folder con.

Neu anh nam trong folder con, ten folder con duoc xem la EAN cua anh do.


8.2 Cac cot chinh
-----------------
Unsorted:
- Anh moi scan vao se nam o day.

Packshot:
- Anh packshot/product main image.

Lifestyle/Human:
- Anh lifestyle co nguoi/model.

Lifestyle/Normal:
- Anh lifestyle khong phai human/model.

Artwork:
- Artwork, label, design asset.

Duplicate:
- Dung de gom cac anh duplicate/variant ma user tu xac nhan.
- Vi du cung mot shot nhung khac file type: .jpg va .png.


8.3 Output folders
------------------
Output bar co cac folder rieng:

- Packshot
- Human
- Normal Lifestyle
- Artwork

Khi chay Copy mode, output duoc chia theo category.


8.4 Action mode
---------------
Trong Settings:

Copy:
- Copy file sang output folder.
- Khong doi file source.

In-folder rename:
- Doi ten ngay trong folder source.
- Nen dung can than hon va nen Preview truoc.


8.5 Naming mode
---------------
Per category:
- Danh so rieng theo tung EAN + category.
- Neu chi co 1 anh trong category va khong bat 1st: ten co the la {EAN}.ext.
- Neu co nhieu anh: {EAN}_1.ext, {EAN}_2.ext.

Continuous:
- Danh so lien tuc theo EAN qua cac category.
- Vi du: {EAN}_1.jpg, {EAN}_2.jpg, {EAN}_3.jpg.

Prefixed:
- Dung prefix category trong ten file.
- Format:
  {EAN}_{PREFIX}_{number}.{extension}

Prefix mac dinh:
- Packshot: Pack_shot
- Human: Human
- Normal Lifestyle: Normal_Lifestyle
- Artwork: Artwork

Vi du:
8809864754188_Pack_shot_1.jpg
8809864754188_Human_1.jpg
8809864754188_Normal_Lifestyle_1.jpg
8809864754188_Artwork_1.jpg


8.6 Custom EAN
--------------
Neu nhap Custom EAN:
- App dung Custom EAN thay cho EAN detect tu folder.
- Ap dung cho cac file duoc process trong lan do.


8.7 Product Name
----------------
Product Name khong tu dong ep naming mode nua.

Neu chi nhap Product Name va khong tick EAN_ProductName:
- Naming mode van chay theo setting user chon.
- Neu dang chon Prefixed, output van la prefix:
  {EAN}_Pack_shot_1.jpg

Neu tick checkbox EAN_ProductName:
- App dung naming continuous theo product name:
  {EAN}_{PRODUCT_NAME}_{number}.ext

Vi du:
8809864754188_MY_PRODUCT_1.jpg
8809864754188_MY_PRODUCT_2.jpg


8.8 Quy tac 1st
---------------
Checkbox 1st o cac cot:
- Cho phep user danh dau anh se duoc uu tien lam anh so 1.

Voi Prefixed mode + Duplicate:
- Neu user keo cac anh duplicate vao Duplicate > PACK SHOT va bat 1st,
  app xem cac file do la cung mot shot so 1.

Vi du:
8809864754188_Pack_shot_1.jpg
8809864754188_Pack_shot_1.png

Tuong tu voi Human:
8809864754188_Human_1.jpg
8809864754188_Human_1.png

Luu y:
- Neu trong cung mot duplicate group co 2 file cung extension cung muon thanh _1.jpg,
  Windows se bi trung ten. App se bao conflict.


8.9 Preview va Apply
--------------------
Nen bam Preview truoc khi Apply.

Preview se hien:
- Current Name
- Output Path
- Status

Neu thay dung:
- Bam Copy hoac Rename.

Neu sai:
- Keo lai anh vao cot dung.
- Sua naming mode/output/custom EAN.
- Preview lai.


8.10 Undo
---------
Sau khi Apply, neu app co log undo:
- Bam Undo de revert thao tac gan nhat.

Luu y:
- Undo phu thuoc vao log trong .ean-renamer\logs.
- Neu file da bi user di chuyen/xoa sau khi rename, Undo co the khong khop.


9. Khi gap loi
--------------
Thu tu xu ly:

1. Dong app va mo lai.
2. Chay REPAIR_GRIMOIRE.bat.
3. Chay DIAGNOSE_GRIMOIRE.bat.
4. Gui file report trong folder diagnostics cho nguoi support.


10. Best practices
-----------------
- Luon Preview truoc khi Rename in-folder.
- Nen dung Copy mode khi test rule moi.
- Nen giu source folder rieng va output folder rieng.
- Khi dung Packshot Browser, nen dat output folder ngoai source folder.
- Nen dat anh duplicate khac file type vao Duplicate column de app giu cung slot number.
- Nen tranh dat output folder trung source folder.
