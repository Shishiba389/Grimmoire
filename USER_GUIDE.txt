GRIMOIRE USER GUIDE
===================

GRIMOIRE is a local Windows application for product-data audit, image review,
EAN file naming, and high-volume folder processing. It does not upload working
folders to a cloud service.

AVAILABLE WORKFLOWS
-------------------

1. Data QC
   Audit Excel/CSV master data, inspect issues, and download review reports.

2. Images Check
   Scan a local image folder, review it in slideshow or gallery mode, and mark
   rejected images. Deletion is permanent after confirmation.

3. EAN Renamer
   Classify one product folder, set output destinations, preview names, then
   copy or rename files by EAN.

4. Bulk Working
   Process many product folders through a focused queue. This is the preferred
   workflow for repeated EAN rename/copy work.

SAFE WORKING RULES
------------------

- Keep source and output folders separate.
- Use Copy mode when a naming rule is new or unverified.
- Always run Preview before Copy or Rename.
- Do not put a generated output folder inside the source folder.
- Make a backup before any in-place rename or confirmed deletion.

BULK WORKING
------------

1. Click Choose folder and select the root that contains product folders.
2. Optionally load Master Data or Import Map to prefill EAN and product names.
3. Use the queue search and status filter to find the next folder.
4. Open one folder. GRIMOIRE loads its full file list only at this point, so a
   large queue remains responsive.
5. Review the automatic image classification. PDF files remain in the queue
   and are placed in Artwork for manual review; PDFs are not sent to CLIP.
6. Select files, then use Move selected to or drag them into a category.
7. Click Manage columns to add a custom category such as Detail shots. Custom
   columns are remembered on that workstation and appear in the output bar.
8. Set output folders, click Preview, resolve conflicts, then Copy or Rename.
9. Click Done or Next to continue through the queue.

EAN RENAMER
-----------

1. Choose one source folder.
2. Move files into the correct category columns.
3. Enter or confirm EAN and product name when required.
4. Choose Copy or Rename in-place, output folders, and naming mode.
5. Review Preview before applying the operation.

DATA QC
-------

1. Open Data QC and upload the original Excel/CSV file.
2. Run the audit and wait for the report to complete.
3. Review findings, fix the source file, and re-run when needed.
4. Download the completed report from the job panel.

IMAGES CHECK
------------

1. Select the highest safe root folder.
2. Scan and review files in gallery or slideshow mode.
3. Mark rejected files.
4. Recheck the deletion count and confirm only when it is correct.

TROUBLESHOOTING
---------------

- Close and reopen the app after a transient error.
- Run REPAIR_GRIMOIRE.bat if dependencies or frontend files are damaged.
- Run DIAGNOSE_GRIMOIRE.bat and keep its output when reporting a reproducible
  problem.
- For an update, use the current release patch exactly as provided and restart
  GRIMOIRE after it completes.

RETIRED MODULES
---------------

EAN Sorter, Packshot Browser, SharePoint browsing, and Image Edit are not part
of this GRIMOIRE build. Image Edit source was moved to its own workspace for a
future standalone application.
