GRIMOIRE INSTALLATION GUIDE
===========================

Muc dich
--------
Tai lieu nay huong dan cai dat GRIMOIRE tren may Windows moi de user co the test
ma khong bi phu thuoc vao duong dan tren may goc.


1. Yeu cau he thong
-------------------
He dieu hanh:
- Windows 10 hoac Windows 11, 64-bit.

Bat buoc:
- Python 3.11 hoac moi hon.
- Node.js 20 hoac moi hon, kem npm.
- Microsoft Edge WebView2 Runtime.
- Quyen doc/ghi trong thu muc GRIMOIRE.

Can cho build desktop app:
- .NET SDK tuong thich voi target net10.0-windows.

Khuyen nghi:
- RAM: 8 GB tro len.
- Disk free: 5 GB tro len, nhieu hon neu xu ly anh lon.
- Internet trong lan cai dat dau tien de tai package Python/npm.


2. Cau truc thu muc can giu nguyen
----------------------------------
Gui cho user ca folder GRIMOIRE, bao gom cac thu muc/file chinh:

- backend
- frontend
- desktop
- SETUP_GRIMOIRE.bat
- START_DESKTOP.bat
- START_GRIMOIRE.bat
- REPAIR_GRIMOIRE.bat
- DIAGNOSE_GRIMOIRE.bat

Khong bat buoc gui:
- backend\.venv
- frontend\node_modules
- backend\node_modules
- diagnostics
- backend\storage\uploads
- backend\storage\outputs

Neu gui cac thu muc dependency san thi app co the chay nhanh hon, nhung setup van
co the tao lai chung tren may user.


3. Cai dat lan dau
------------------
Buoc 1: Copy folder GRIMOIRE vao may user.

Vi du:
C:\Tools\GRIMOIRE
D:\Apps\GRIMOIRE

Khong can dat project o mot duong dan co dinh.

Buoc 2: Mo folder GRIMOIRE.

Buoc 3: Double-click:
SETUP_GRIMOIRE.bat

Script nay se:
- Kiem tra Python.
- Kiem tra Node.js/npm.
- Tao backend\.venv neu chua co.
- Cai Python dependencies tu backend\requirements.txt.
- Cai backend Node dependencies cho image worker.
- Cai frontend Node dependencies.
- Tao cac thu muc runtime trong backend\storage.

Buoc 4: Neu setup thanh cong, double-click:
START_DESKTOP.bat


4. Cach chay app
----------------
Che do desktop:
- Chay START_DESKTOP.bat
- App se mo Grimoire.exe tu desktop\bin\Release\net10.0-windows.
- Backend se duoc desktop app tu dong start neu tim thay backend\.venv.

Che do dev browser:
- Chay START_GRIMOIRE.bat
- Backend chay tai http://127.0.0.1:7788
- Frontend dev server chay tai http://127.0.0.1:5173


5. Repair khi bi loi
--------------------
Neu user gap loi sau khi copy folder, doi may, hoac dependency bi hong:

Double-click:
REPAIR_GRIMOIRE.bat

Script nay se:
- Kiem tra Python/Node/npm.
- Tao lai backend\.venv neu thieu.
- Cai lai Python dependencies.
- Cai lai backend/frontend npm dependencies.
- Build lai frontend.
- Build lai desktop app neu may co .NET SDK.


6. Diagnose de gui report loi
-----------------------------
Neu app van loi:

Double-click:
DIAGNOSE_GRIMOIRE.bat

Script se tao report trong:
diagnostics\grimoire-diagnose-YYYYMMDD-HHMMSS.txt

Gui file report nay cho nguoi support.


7. Cac loi thuong gap
---------------------
Loi: Python is not installed or not on PATH
- Cai Python 3.11+.
- Khi cai, tick "Add python.exe to PATH".
- Chay lai SETUP_GRIMOIRE.bat.

Loi: Node.js is not installed or not on PATH
- Cai Node.js 20+.
- Dam bao npm duoc cai kem.
- Chay lai SETUP_GRIMOIRE.bat.

Loi: Backend failed to start
- Chay REPAIR_GRIMOIRE.bat.
- Neu van loi, chay DIAGNOSE_GRIMOIRE.bat va gui report.

Loi: Port 7788 dang bi chiem
- Tat app khac dang dung port 7788, hoac restart may.
- Desktop app co the tu tim port khac, nhung dev script START_GRIMOIRE.bat dung 7788 mac dinh.

Loi: Khong build duoc desktop app
- Cai .NET SDK tuong thich net10.0-windows.
- Neu chi muon test desktop binary da co san, co the chay START_DESKTOP.bat ma khong can build lai.


8. Ghi chu dong goi
-------------------
Khi gui cho user, nen zip folder GRIMOIRE sau khi da xoa cac thu muc runtime lon:

- backend\.venv
- backend\node_modules
- frontend\node_modules
- diagnostics
- backend\storage\uploads
- backend\storage\outputs

User chi can giai nen, chay SETUP_GRIMOIRE.bat, roi START_DESKTOP.bat.
